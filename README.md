# 🦒 Giraffe Tracking System

## 📋 Системные требования
- Python 3.8+
- pip (пакетный менеджер Python)
- FFmpeg (для обработки видео) - [Инструкция по установке](https://ffmpeg.org/download.html)
- Доступ в интернет (для установки зависимостей)

## 🚀 Быстрый старт

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/Vamprsii/practise_sii.git
   cd practise_sii
   ```

2. **Создайте виртуальное окружение** (рекомендуется):
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/MacOS
   venv\Scripts\activate     # Windows
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте необходимые директории**:
   ```bash
   mkdir -p static/uploads static/results static/reports
   ```

5. **Запустите приложение**:
   ```bash
   uvicorn app.main:app --reload
   ```

6. **Откройте в браузере**:
   ```
   http://127.0.0.1:8000/
   ```

## 🖥️ Использование системы

### Основные функции
1. **Загрузка файлов**:
   - Поддерживаются изображения (JPG, PNG) и видео (MP4, AVI, MOV, MKV)
   - Все файлы сохраняются в `static/uploads/`
   - Результаты обработки сохраняются в `static/results/`

2. **Просмотр результатов**:
   - Для изображений: отображаются оригинал и результат с bounding boxes
   - Для видео: доступен плеер для оригинального и обработанного видео
   - Отображается количество обнаруженных жирафов и время обработки

3. **Управление историей**:
   - Полная история доступна на главной странице
   - Возможность очистки всей истории

### 📊 Генерация отчетов
- **PDF отчет**: `/report/pdf`
- **Excel отчет**: `/report/excel`

Отчеты сохраняются в `static/reports/` и автоматически скачиваются.
